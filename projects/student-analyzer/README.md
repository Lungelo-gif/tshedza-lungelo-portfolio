# Student Performance Data Analyzer

## Overview
A beginner-friendly, AI-assisted Python data project that reads student marks from CSV data, calculates averages, ranks students, assigns performance categories, and identifies subject trends.

## Technologies
Python and CSV.

## Concepts demonstrated
Reading structured data, functions, loops, conditions, calculations, aggregation, sorting, and basic data analysis.

## Run it
Keep `student_analyzer.py` and `student_scores.csv` together, then run:
`python student_analyzer.py`

## How to explain it
The CSV file contains the raw input data. Python reads each row and converts the subject marks into numbers. It calculates each student's average and assigns a performance category. It then calculates class and subject averages, sorts students by performance, and identifies the strongest and weakest subject.

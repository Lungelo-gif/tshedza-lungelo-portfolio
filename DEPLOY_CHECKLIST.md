# Deployment checklist

1. Create/publish the SkillBridge AI repository as `skillbridge-ai` so the portfolio GitHub button resolves.
2. Upload all files from this portfolio folder to `Lungelo-gif/tshedza-lungelo-portfolio`.
3. Keep the `certificates/` folder intact so certificate links work.
4. Confirm GitHub Pages is serving from the correct branch/root.
5. Open the live portfolio and click every certificate card marked “View certificate”.
6. Test the SkillBridge AI live demo and GitHub buttons.
7. Re-check the Azure Administrator Associate card after the exam; only change it to Certified after passing.
